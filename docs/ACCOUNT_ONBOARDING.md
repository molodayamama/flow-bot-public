# Подготовка Google-аккаунта

Используйте собственный аккаунт с доступом к Google Labs Flow. Аккаунты,
пароли, резервные коды и cookies не должны находиться в репозитории.

1. Создайте отдельный каталог Chrome-профиля, например `google_profile_acc2`.
2. Откройте Chrome с этим профилем и вручную войдите в Google и Flow.
3. Убедитесь, что аккаунту доступны нужные модели и квоты.
4. Закройте Chrome с этим профилем перед запуском бота.
5. Добавьте профиль в локальный `.env`:

```dotenv
FLOW_ACCOUNTS=main=./google_profile;acc2=./google_profile_acc2
```

Если нужен прокси, задайте его только в локальном окружении. Пример с локальным
прокси без учётных данных:

```dotenv
FLOW_ACCOUNTS=main=./google_profile|proxy=http://127.0.0.1:8118
```

Наличие прокси не гарантирует доступ к Flow или успешную генерацию. Параметры
сети, подписки и ограничения Google нужно проверять для своего аккаунта.

`login.py` — вспомогательный интерактивный скрипт, который удаляет и пересоздаёт
каталог `USER_DATA_DIR` (по умолчанию `google_profile/`). Используйте его только
для нового профиля либо после проверенной резервной копии. Он не нужен для
каждого запуска. На headless-сервере авторизация требует настроенного дисплея.

После запуска состояние пула доступно администратору через `/admin_accounts`.
`/acc_off <id>` и `/acc_on <id>` управляют доступностью аккаунта.
Полная конфигурация описана в [ENV_SETUP.md](ENV_SETUP.md).
