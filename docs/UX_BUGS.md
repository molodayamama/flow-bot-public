# UX Bugs & Observations — @photozhab_bot

История: первый прогон 2026-06-14 (Telethon-симуляция). Файл перезаписан в чистом
UTF-8 и перепроверен 2026-06-21 (предыдущая версия была в битой кодировке).

Статусы: `fixed` — проверено, починено; `by-design` — оставляем намеренно;
`recheck` — нужен прицельный повторный E2E-прогон, чтобы подтвердить.

---

## Перепроверено 2026-06-21

### BUG-001 · Любой текст в idle → мгновенная генерация без подтверждения — `fixed`

Проверено по коду (`flow_bot.py`, хвост текст-хендлера): обычный текст «вхолодную»
теперь уходит в `show_wizard` с сохранённым промптом — генерация только после
кнопки «✨ Сгенерировать». Комментарий в коде: «Не генерируем вслепую». Кредиты
на «привет» больше не списываются.

### BUG-002 · Полное меню скрыто / неочевидно — `fixed` (в основном)

`/menu` отдаёт полное меню из 8 кнопок; `/start` тоже. Slash-команды работают
(см. BUG-004). Reply-keyboard остаётся коротким по дизайну (быстрые действия),
но полный набор доступен и через `/menu`, и через slash-команды.

### BUG-003 · Статус «Создаю…» без кнопки отмены — `by-design`

Статус-сообщение генерации не имеет кнопки «Отмена». Оставляем намеренно:
генерация короткая (картинка ~10–20с, видео ~90с), кредиты уже списаны и уходят
провайдеру до старта, а настоящая отмена in-flight задачи рискованна (гонки,
двойной рефанд). Если понадобится — отдельная задача с корректной отменой+рефандом.

### BUG-004 · Slash-команды /help, /ideas, /referral не отвечали — `fixed`

Проверено вживую 2026-06-21: все три отвечают (`/help` → справка, `/ideas` →
идеи/шаблоны, `/referral` → реферальная ссылка).

## Требуют прицельного повторного прогона (`recheck`)

Заявлены в прогоне 2026-06-14, но НЕ перепроверены 2026-06-21 — могут быть уже
исправлены, нужен отдельный E2E-проход с инспекцией каждого экрана:

- BUG-005 · «🏠 Меню» (reply) и «🏠 Главное меню» (inline) — две кнопки с разным
  поведением. `recheck`.
- BUG-006 · Тест-пакет «🧪 Тест · 10 кр · 1⭐» виден всем. Вероятно `fixed`:
  в `STARS_PACKS` тест-пак помечен `test: True` и скрыт от обычных юзеров
  (виден только админам) — подтвердить визуально. `recheck`.
- BUG-007 · «Создаю» — два сообщения вместо одного. `recheck`.
- BUG-008 · Экран настроек не объясняет, как ввести промпт. Частично снято
  новым prompt-first флоу, но текст подсказки стоит проверить. `recheck`.
- BUG-009 · Названия моделей «Nano Banana 2 / Pro» — непонятны новичку. `recheck` (minor).
- BUG-010 · Старые inline-кнопки → `DataInvalidError`. `recheck` (minor).
- BUG-011 · Баланс: нет цены видео. `recheck` (minor).
- BUG-012 · Пакеты кредитов: нет пояснения, что такое «кредиты». `recheck` (minor).

## Что работает хорошо (подтверждено)

- `/help`, `/ideas`, `/referral`, `/start`, `/menu` — отвечают.
- Image-визард: текст → экран настроек (кол-во/формат/модель) + «✨ Улучшить
  промпт · 5 кр» + «Сгенерировать»; генерация только по кнопке.
- Video-визард: prompt-first, тоггл «⚡ Быстро / 💎 Качество», «✨ Улучшить промпт».
- «Изменить моё фото»: экран подтверждения с «✨ Улучшить запрос» и «Применить».
