# План роста: Telegram outreach и короткие видео

Дата: 2026-06-11

Цель: получить первые стабильные активации пользователей без платной рекламы, не
сжигая репутацию проекта и Telegram-аккаунты.

## Принципы

- Не нарушать правила Telegram, TGStat, соцсетей и площадок размещения.
- Не использовать массовые unsolicited ЛС по участникам чатов.
- Не парсить личные данные пользователей для обхода согласия.
- Не использовать аккаунты-расходники, impersonation, скрытую рекламу или обход
  антиспам-систем.
- Любой outreach должен быть либо разрешен правилами сообщества, либо согласован
  с админом, либо идти по opt-in сигналу пользователя.
- Результаты считать по активациям и оплатам, а не по количеству отправленных
  сообщений.

## Канал A: TGStat, Telegram-чаты и outreach

### Рабочая гипотеза

Целевая аудитория уже обсуждает свои задачи в Telegram: селлеры маркетплейсов,
SMM-специалисты, блогеры, AI-энтузиасты, малый бизнес, дизайнеры карточек
товаров. Задача канала — найти живые сообщества, понять боли и аккуратно
получить первых пользователей через полезное участие, админские размещения и
разрешенный личный контакт.

### Этап 1. Карта сообществ

Срок: 1-2 дня.

Бюджет: 0-1000 руб.

Действия:

1. Через TGStat собрать 50-100 чатов и каналов по сегментам:
   - селлеры Wildberries/Ozon;
   - SMM и контент-маркетинг;
   - нейросети и AI-инструменты;
   - блогеры, Reels/TikTok/Shorts;
   - фото/дизайн/карточки товаров;
   - pet-сообщества, если тестируется сценарий "оживить питомца".
2. Для каждого сообщества записать:
   - название и ссылку;
   - размер аудитории;
   - активность обсуждений;
   - правила рекламы и ЛС;
   - контакт админа;
   - частые боли и формулировки пользователей;
   - подходит ли сообщество для публичного ответа, админского поста или только
     для наблюдения.
3. Отобрать 15-20 самых релевантных сообществ для первого теста.

Метрики:

- количество найденных сообществ;
- доля активных чатов;
- количество чатов, где разрешены полезные ответы/кейсы;
- количество админов, у которых можно запросить размещение.

### Этап 2. Сообщения и офферы

Срок: 1 день.

Бюджет: 0 руб.

Подготовить 3-5 коротких офферов под разные боли:

- "Оживить фото питомца" — эмоциональный вау-сценарий для массовой аудитории.
- "Карточка товара на белом фоне" — утилитарный сценарий для селлеров.
- "AI-фото для пары/аватарки" — вирусный пользовательский сценарий.
- "Быстрое видео из фото" — демонстрация Flow video без сложных настроек.

Формат сообщения:

- коротко;
- от первого лица без фальшивой массовой рекламы;
- с конкретным примером результата;
- без давления, спама и обещаний "заработка";
- с честным указанием, что это бот/инструмент.

Пример безопасной структуры:

```text
Привет. Я тестирую Telegram-бота для быстрых AI-картинок и видео.
Для селлеров сейчас проверяю сценарий: фото товара -> чистый белый фон/карточка.
Могу бесплатно сделать 1 тестовый пример и забрать обратную связь, если актуально.
```

Guardrails:

- не отправлять такие сообщения массово незнакомым участникам чатов;
- использовать ЛС только если пользователь сам попросил пример, оставил явный
  запрос или правила сообщества это допускают;
- для чатов с запретом рекламы сначала писать админу;
- прекращать контакт после отказа или отсутствия интереса.

### Этап 3. Публичное участие и админские размещения

Срок: 3-7 дней.

Бюджет: 0-1000 руб.

Действия:

1. В выбранных чатах 3-5 дней наблюдать за реальными вопросами.
2. Отвечать публично только там, где ответ уместен: "могу показать пример",
   "собрал быстрый способ", "вот до/после".
3. В чатах с жесткими правилами писать админам и просить разрешение на:
   - один полезный кейс-пост;
   - бесплатный тест для участников;
   - бартер: демо-контент сообществу за разрешение на публикацию.
4. Вести отдельную таблицу контактов админов и результатов.

Метрики:

- число публичных полезных ответов;
- число разрешенных размещений;
- CTR по ссылке на бота;
- стартов бота с `seed_`/реферальной меткой;
- доля пользователей, сделавших первую генерацию;
- жалобы, удаления сообщений, баны: целевой показатель 0.

### Этап 4. Малый opt-in тест

Срок: 7 дней.

Бюджет: 0-1000 руб.

Проводить только по разрешенным контактам:

- люди сами запросили пример;
- человек написал в ответ на публичный пост;
- админ разрешил личный контакт;
- пользователь пришел через форму/бота/реферальную ссылку.

Лимиты безопасности:

- ручная отправка;
- маленькие партии;
- паузы между контактами как защита качества коммуникации, а не обход банов;
- стоп при первых признаках негатива: жалобы, блокировки, предупреждения,
  удаления сообщений.

Метрики:

- opt-in contacts;
- reply rate;
- activation rate;
- first generation rate;
- paid conversion;
- complaints/block rate;
- cost per activated user.

### Риски канала A

- Спам-риск: массовые ЛС незнакомым людям могут привести к жалобам, банам и
  репутационному ущербу.
- Этический риск: "живое сообщение от человека" не должно превращаться в
  обман, скрытую рекламу или имитацию личного знакомства.
- Правовой риск: сбор и использование персональных данных без основания может
  нарушать требования площадок и законодательства.
- Операционный риск: канал может потреблять много времени при низкой
  масштабируемости.

Решение: использовать TGStat для исследования сообществ, а не для массового
спама; делать акцент на публичной пользе, админских договоренностях, opt-in и
измеримой активации.

## Канал B: Reels, TikTok, Shorts

### Рабочая гипотеза

Короткие видео лучше подходят для массового объяснения AI-бота, потому что
показывают результат за 5-20 секунд: было фото, стал ролик; был товар на плохом
фоне, стала карточка; была обычная фотография питомца, появилось эмоциональное
видео.

Приоритет: сначала вручную найти работающий формат, затем масштабировать.

### Этап 1. Контент-матрица

Срок: 1 день.

Бюджет: 0 руб.

Собрать 10-15 роликов вручную по темам:

1. "Оживи фото питомца" — до/после, эмоция, 8-12 секунд.
2. "Карточка товара на белом фоне за 10 секунд" — боль селлеров.
3. "AI-фото пары" — вирусный пользовательский сценарий.
4. "Фото -> видео" — простой wow-результат без объяснения технологии.
5. "3 идеи для контента из одной фотографии" — практический формат для SMM.

Структура ролика:

- 0-2 сек: сильный визуальный hook;
- 2-7 сек: до/после или процесс;
- 7-12 сек: результат крупно;
- финал: короткий CTA в Telegram-бот.

Запреты:

- не использовать чужие фото людей/товаров без прав;
- не обещать гарантированный доход;
- не скрывать, что результат сделан AI;
- не перегружать ролик интерфейсом и объяснениями.

### Этап 2. Публикация вручную

Срок: 7-10 дней.

Бюджет: 0 руб.

Действия:

1. Опубликовать 10-15 роликов на своих аккаунтах.
2. Для каждого ролика сохранить:
   - тему;
   - hook;
   - длительность;
   - визуальный сценарий;
   - площадку;
   - ссылку;
   - просмотры через 24/72 часа;
   - переходы в бот;
   - первые генерации;
   - оплаты.
3. Не менять сразу много переменных: тестировать один hook или один сценарий за
   раз.

Метрики:

- views;
- удержание первых 3 секунд;
- досмотры;
- CTR в профиль/ссылку;
- start bot;
- first generation;
- paid conversion;
- revenue per 1000 views.

### Этап 3. Выбор победителей

Срок: 1-2 дня после первых 10-15 роликов.

Критерии победителя:

- выше среднего удержание первых секунд;
- есть переходы в бота;
- пользователи доходят до первой генерации;
- сценарий можно повторять серийно;
- нет сильного негатива в комментариях.

Ожидаемые сильные кандидаты:

- "Оживить питомца" — массовый эмоциональный wow-эффект.
- "Карточка товара" — понятная экономия денег и времени для селлеров.

### Этап 4. Масштабирование

Срок: после появления 2-3 доказанных форматов.

Бюджет:

- 0 руб. при самостоятельном производстве;
- 3000-15000 руб. на первые заказы монтажерам/UGC-исполнителям;
- фермы коротких видео рассматривать только после ручного подтверждения формата.

Правило масштабирования:

Сначала 10-15 роликов вручную, затем 30-50 вариаций победивших форматов. Не
отдавать TikTok/Reels-ферме сырой непроверенный оффер.

Контроль качества:

- один понятный hook;
- результат виден без чтения текста;
- CTA ведет в Telegram-бота;
- ролик не выглядит как generic AI-реклама;
- каждую неделю отключать слабые темы и усиливать победителей.

### Риски канала B

- Низкое качество фермы может испортить первые сигналы.
- Сырые аккаунты могут долго не набирать охваты.
- Вирусные просмотры не равны оплатам.
- Контент с чужими фото/брендами может создать претензии.

Решение: начинать вручную, считать не только просмотры, но и активации в боте,
использовать свои или разрешенные материалы, масштабировать только доказанные
форматы.

## Общая воронка и аналитика

Минимальная разметка:

- отдельные deep links или seed-метки для каждого канала;
- отдельные метки для сегментов: `wb`, `smm`, `ai`, `pet`, `shorts`;
- таблица экспериментов с датой, гипотезой, ссылкой, затратами и результатом.

Основные KPI:

- start bot;
- first generation;
- second generation;
- paid conversion;
- revenue;
- cost per activated user;
- complaint/block rate;
- retention D1/D7.

Решение о продолжении:

- Канал продолжается, если дает дешевые активации и нет жалоб.
- Канал останавливается, если рост держится только на спаме, жалобах или банах.
- Масштабирование разрешено только после доказанного формата и понятной
  экономики.

## Недельный план

День 1:

- собрать карту 50-100 Telegram-сообществ;
- выбрать 15-20 тестовых;
- подготовить 5 офферов;
- собрать 10 идей коротких видео.

Дни 2-3:

- сделать первые 5 роликов;
- начать публичное наблюдение и полезные ответы в Telegram;
- написать админам релевантных чатов с запросом разрешенного размещения.

Дни 4-7:

- опубликовать 10-15 роликов;
- провести малый opt-in outreach;
- собрать метрики по бот-стартам и первым генерациям;
- выбрать 2-3 лучших hook/оффера.

Неделя 2:

- удвоить лучшие короткие видео;
- повторить Telegram-тест только в сообществах без негатива;
- посчитать cost per activated user и paid conversion;
- принять решение: усиливать органику, покупать размещения у админов или
  закрывать слабые сегменты.
