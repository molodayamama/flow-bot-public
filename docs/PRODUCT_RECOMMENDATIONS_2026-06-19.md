# Рекомендации по продукту на основе болей лидов (2026-06-19)

Основано на сканах лидов в Telegram (`docs/LEAD_RESEARCH_2026-06-19.md`,
`lead_scan_runs/`). Выделились два сегмента спроса, у каждого своя боль и своя
тактика:

- **tool_seeking** — хотят бот / нейросеть / сервис, чтобы сделать визуал самим.
  Прямой фит для бота Photozhab: даём ссылку + один пример по их категории.
- **done_for_you** — хотят человека/команду, которые сделают всё за них
  («ищу дизайнера инфографики»). Это больший сегмент. Они выбирают человека,
  потому что не доверяют качеству DIY-инструментов или у них нет времени. От
  холодной ссылки на бота сами они не сконвертятся.
- **advice** — спрашивают, что работает (стиль дизайна, правила маркетплейсов).
  Мягкий контакт.

Важный вывод второго захода (102 чата, включая AI/нейросети-чаты): сегмент
**tool_seeking почти отсутствует** — лидов, которые прямо просят «посоветуйте
бота для генерации» нашлось всего ~3, и те шумные. Зато чаты **переполнены
рекламой ботов-конкурентов** «загрузи фото → готовая карточка» (SSA Navigator,
OblozhkaAI, ABCardo и т.п.). Трактовка: спрос на «бот для карточек» уже
подтверждён рынком, но (а) предложение перегрето рекламой и (б) люди, которым
нужен инструмент, не пишут в чат — они либо идут к уже разрекламированным ботам,
либо нанимают человека. Поэтому рабочие сегменты — **done_for_you (~292)** и
**advice (~441)**, а бота надо проталкивать не «в лоб как ещё один бот», а через
эти два входа (ниже).

## Боли, которые видно в сообщениях лидов (по частоте)

1. Карточки / инфографика для WB/Ozon — безусловно доминирующий запрос.
2. Привязка к маркетплейсу (форматы и правила WB / Ozon / Яндекс Маркет).
3. «Сам / новичок / без опыта» — хочет сделать сам, но не хватает навыка (~40).
4. Одежда / на модели — продавцы одежды просят кадры на модели (~33).
5. Быстро / дёшево / бюджет — «за 5 минут», «в 10 раз дешевле» (~32).
6. Фото → видео / оживить фото / reels для карточек (~28).
7. Замена фона / белый фон / предметка (~15).
8. «Какой нейросетью / каким сервисом» — интерес к AI-инструментам (~65 упоминаний AI).

## A. Что добавить или вынести наверх (flow_bot)

1. **Сценарий в один тап «Карточка WB/Ozon».** Запрос №1 — карточка товара /
   обложка. В `prompts_lib.py` уже есть `product_card` и материалы по обложке —
   вынести это в пресет верхнего уровня: загрузил фото товара → выбрал категорию
   → получил карточку с понятными акцентными зонами. Сейчас это спрятано в
   Ideas Hub.
2. **Фон / белый фон как действие верхнего уровня.** «убрать/поменять фон, белый
   фон» — самый низкий порог входа. `marketplace_white_bg` уже есть — сделать его
   отдельной кнопкой по цене изображения (10 кредитов), а не просто идеей-промптом.
3. **Пресет «одежда → на модели».** Продавцы одежды — отдельный повторяющийся
   сегмент. Сценарий «одежда → на модели» отстраивает от обычных бот-генераторов
   карточек.
4. **Корректные пропорции под маркетплейс по умолчанию.** В enum'ах соотношений
   уже есть 3:4 / 4:3 (`PORTRAIT_THREE_FOUR`). Предложить выбор в один тап
   «WB (3:4) / Ozon / ЯМ», чтобы результат был сразу готов к загрузке — это
   снимает реальное трение, на которое жалуются лиды.
5. **Клин «фото → видео».** Многие done_for_you-лиды ищут спеца по «AI-видео /
   оживить фото». Самообслуживание «оживить фото товара для карточки/reels» —
   более маржинальный клин; вынести его заметно (видео уже премиальное).

## B. Проблема читаемого русского текста (самый сильный дифференциатор)

Инфографике нужен чистый русский текст на картинке. Чистая диффузия коверкает
кириллицу — это причина №1, почему продавцы не доверяют «AI-карточкам» и выбирают
живого дизайнера. Рекомендация: **рендерить текст отдельным слоем-шаблоном поверх
AI-фона** (программные текстовые зоны), а не полагаться на модель, которая рисует
буквы. Бот, который стабильно выдаёт читаемый русский текст инфографики, обойдёт
большинство конкурентов (ABCardo, OblozhkaAI, SSA Navigator, Neiro-card) именно по
тому критерию, который важен продавцам. Сначала POC: один шаблон с заголовком +
3 буллит-зонами поверх сгенерированного фона.

## C. Онбординг и конверсия

6. **Демо на первом запуске по фото самого пользователя.** Конкуренты ведут через
   «загрузи фото → получи карточку». Повторить это: первая загрузка нового
   пользователя сразу возвращает одну карточку из стартового гранта
   `STARTER_CREDITS = 30`. Показать результат до решения об оплате.
7. **Позиционирование «черновик до дизайнера».** Большинство лидов хотят человека,
   потому что боятся качества DIY. Переформулировать бота как «сделай черновик /
   проверь 2-3 гипотезы за 10 кредитов до оплаты дизайнера» — это конвертирует
   скептиков из done_for_you в пробующих, вместо лобовой борьбы с их предпочтением.
8. **Вести с «не подписка».** Лиды чувствительны к цене. Видимая поштучная цена +
   бесплатный старт бьют подписочных конкурентов (например, Neiro-card ~1490 руб/мес).
   Копирайт держать провайдер-нейтральным (без слов Google/Flow/капча, по CLAUDE.md).
9. **Галерея «до/после»** реальных карточек прямо в боте — чтобы строить доверие у
   DIY-скептиков, которых большинство.

## D. Тактика контакта по сегментам (использует очередь лидов)

- **tool_seeking** → отвечаем ссылкой на бота + один пример по их категории; они
  прямо хотят инструмент.
- **done_for_you** → предлагаем тариф «под ключ» с помощью бота: оператор делает
  карточки в Photozhab и отдаёт готовый результат. Это монетизирует ~300
  done_for_you-лидов, которые сами в боте работать не будут, и заодно даёт контент
  (готовые карточки становятся примерами для галереи/кейсов).
- **advice** → реально полезный ответ, мягкое упоминание только там, где правила
  чата позволяют.
- Отслеживать конверсию по чату через deep-link `/admin_channels <seed>` (см.
  `docs/GROWTH_PLAN.md`). Отвечать вручную; никаких авто-ЛС и массовых постов.

## E. Очерёдность (сначала самые маленькие полезные шаги)

1. Вынести белый фон + карточку товара в кнопки верхнего уровня в один тап
   (мало работы, самая частая боль).
2. Добавить пресеты пропорций под маркетплейс в эти сценарии.
3. Сделать POC текстового слоя для инфографики (настоящий ров/моат).
4. Запустить outreach «под ключ» для done_for_you, используя бота внутри.
5. Добавить пресет «одежда → на модели».

Ограничения без изменений: очередь лидов — для ручного контакта по правилам чатов;
экспортируются только публичные id вида `chat/message_id`; никаких личностей и
авто-ЛС.
